# 2 需求分析

本章以系统用例图为唯一用例来源，围绕“学生用户”和“管理员”两个参与者描述需求范围、数据对象、功能边界、非功能约束、界面要求、用例约束和需求追踪关系。

## 2.1 用户角色与业务场景

### 2.1.1 用户角色

| 角色 | 角色说明 | 主要业务目标 |
| --- | --- | --- |
| 学生用户 | 学习闭环的使用者，面向个人学习计划、成长树、资源、推荐路径和学伴交互 | 查看学习状态，获得学习路径推荐，采纳路径，生成和查看学习资源，查看个人学习大纲，与学伴交互 |
| 管理员 | 教学内容与运行维护的管理者，面向文件、图谱、大纲、材料、任务和 Total Agent 运行配置 | 管理教学文件和知识图谱，维护教学大纲，发布教学材料，管理后台任务，查看 Total Agent 定义和同步运行状态 |

系统坚决维持上述两个参与者。后续功能、界面和追踪矩阵均不得引入第三类业务参与者。

## 2.2 数据需求

| 编号 | 数据对象 | 主要字段 | 来源 | 使用场景 |

| D-012 | Total Agent 运行数据 | `agent_id`, `definition`, `sync_state`, `sse_events`, `runtime_status` | Total Agent 管理与运行 | 查看totalAgent定义、totalAgent同步/SSE运行、学伴交互 |

### 2.2.2 数据处理要求

| 编号 | 要求 | 说明 |
| --- | --- | --- |
| DR-001 | 角色隔离 | 学生用户只能访问自己的学习成长树、个人大纲、推荐、计划和资源；管理员访问教学内容与运维对象。 |
| DR-002 | 课程隔离 | 学习成长树、个人大纲、推荐路径、学习计划和资源均应按课程或教学大纲维度隔离。 |
| DR-003 | 状态可追踪 | 推荐、资源、图谱、大纲、Job、Total Agent 同步均应保留状态字段，支持列表和详情页展示。 |
| DR-004 | 文件可定位 | 上传文件、生成资源和教学材料需要保留可定位的文件或内容引用。 |
| DR-005 | 运行事件可展示 | JobChecker 与 Total Agent SSE 运行过程需要形成可展示的运行事件。 |
| DR-006 | 成长树可更新 | 学习成长树应支持读取、生成和增量更新，不将未触达内容误写为已掌握状态。 |

### 2.3.2 功能约束

| 编号 | 约束 | 说明 |
| --- | --- | --- |
| FR-001 | 用例来源约束 | 功能需求只能来自 2.1.2 提取的用例，不新增独立业务用例。 |
| FR-002 | 学生侧闭环约束 | 学生侧功能围绕成长树、大纲、推荐、计划、资源和学伴交互形成学习闭环。 |
| FR-003 | 管理侧范围约束 | 管理员只处理教学内容和运维对象，不直接修改学生私有学习状态，除非通过教学内容间接影响后续学习。 |
| FR-004 | 推荐采纳约束 | 推荐详情可被采纳路径扩展，采纳后才能形成当前学习计划。 |
| FR-005 | 大纲初始化约束 | 查看个人学习大纲时，如果不存在个人大纲，应先执行初始化。 |
| FR-006 | 资源详情约束 | 查看资源详情必须建立在可获得资源列表或资源标识的基础上。 |
| FR-007 | 图谱创建约束 | 创建图谱依赖已有文件、资料或课程内容。 |
| FR-008 | SSE 运行约束 | Total Agent SSE 运行应提供可追踪事件，不以不可见长任务阻塞管理员判断。 |

## 2.4 非功能需求

| 编号 | 类型 | 需求 |
| --- | --- | --- |
| NFR-001 | 可用性 | 学生常用页面应能清晰展示当前状态、列表、详情和下一步操作。 |
| NFR-002 | 性能 | 列表类页面应优先返回摘要字段，详情内容按需加载。 |
| NFR-003 | 可靠性 | 文件上传、图谱创建、大纲生成、资源生成和 Job 执行失败时必须返回明确错误状态。 |
| NFR-004 | 可追踪性 | 推荐、资源、成长树、大纲、图谱、Job 和 Total Agent 运行需要保留可追踪状态。 |
| NFR-005 | 安全性 | 管理员接口必须鉴权；学生用户不得越权访问其他用户数据或未发布材料。 |
| NFR-006 | 一致性 | 被采纳的推荐路径、当前学习计划和后续资源生成应使用同一课程和用户上下文。 |
| NFR-007 | 可维护性 | 表现层、逻辑层、持久层职责分离；页面名称不得承担业务处理含义。 |
| NFR-008 | 可扩展性 | 图谱、文件、资源和 Agent 运行状态应支持后续扩展类型。 |
| NFR-009 | 可观测性 | JobChecker 和 Total Agent SSE 运行应具备状态事件、错误信息和完成标识。 |
| NFR-010 | 兼容性 | 文档、图谱、资源和大纲数据应支持结构化内容与文件引用并存。 |

## 2.6 用例约束

### 2.6.1 UC-001 查看学习成长树

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-001 |
| 用例名称 | 查看学习成长树 |
| 参与者 | 学生用户 |
| 功能简述 | 学生查看当前课程下的学习成长树，理解已触达节点、薄弱节点和掌握状态。 |
| 前置条件 | 学生用户已登录；存在课程或学习上下文。 |
| 后置条件 | 页面展示成长树；如成长树缺失，可通过扩展用例生成或更新。 |
| 基本路径 | 1. 学生进入学习成长树页面；2. 系统读取用户与课程上下文；3. 系统查询成长树数据；4. 页面展示节点、关系和状态。 |
| 扩展路径 | 成长树不存在或过期时，触发 UC-002 生成/更新学习成长树。 |
| 主要数据 | 学习成长树、用户身份数据、课程/教学大纲。 |
| 业务规则 | 只能展示当前学生用户自己的成长树。 |
| 异常处理 | 数据不存在时展示未生成状态；读取失败时展示错误提示并允许重试。 |

### 2.6.2 UC-002 生成/更新学习成长树

| 项目 | 内容 |
| --- | --- |
| 用例编号 | UC-002 |
| 用例名称 | 生成/更新学习成长树 |
