# 9 项目创新点

## 9.1 技术创新点

1. **时序知识图谱 RAG 检索**。学习资源检索基于 KnowLion 时序知识图谱，RAG 证据附带显式相关度评分，低相关证据返回 `warning` 而非生成不可追踪的高置信回答。

2. **知识点级学习成长树**（Study Graph）。记录学生真实触达的知识节点和掌握度，随学习事件增量生长。与推荐路径图分离——后者是"可以学的"，前者是"真实学了的"。

3. **多 Agent 工具链编排与结构化状态追踪**。Total Agent 将上下文加载、意图识别、路径推荐、资源生成、答疑和反馈闭环拆为可测试工具链，并通过 `tool_trace` 和 `tool_status_events` 暴露全过程状态。

4. **自演化 tag 式记忆**。学伴 Agent 从对话中自行判断该记住什么（`create_memory_tag`）、该忘记什么（`delete_memory_tag`），tag 随时间累积演化，形成独立于总 Agent 的行为闭环。

5. **跨学科终身学习记录**。学生是学习记录树的根节点，学科为中间层。全部学科树在查询时聚合，支持单科聚焦和跨学科总览，不打破按 `user + syllabus` 的持久化隔离。

## 10.2 功能创新点

1. 从自然语言学习目标到个性化路径推荐、多形态资源生成、学习反馈和成长树更新的完整闭环。

2. 多形态学习资源生成管道：规划 → 检索 → 草稿 → LLM 生成 → 结构化校验 → 多格式渲染（文档、测验、思维导图、编程练习、PPT）。

3. 结构化即时答疑：区分概念解释、学习策略、练习帮助三种问题类型，返回带证据引用、计划引用、薄弱点匹配和下一步建议的 `answer` payload。

4. 专属虚拟学伴：每个学生拥有独立学伴 Agent，跟踪学习进度并在学习路径更新时主动生成学习提示。

## 10.3 应用价值

对**学生**：从自然语言目标出发，获得个性化路径、贴合当前步骤的资源、即时答疑，以及可视化的学习成长记录。

对**教师**：获取课程层面薄弱点摘要和学生个体成长树，辅助教学调整。

对**平台**：将大模型能力从问答插件升级为可编排、可追踪、可演示的多 Agent 学习后端。
